# 可拖动分隔线与布局记忆（Resizable Splitters）

> 各视图窗格之间的分隔线可拖动调整宽度 / 高度，位置写盘，下次启动沿用。状态：**已实现**（2026-11-15 更新；
> 单元测试覆盖分隔线拖动、钳制与布局文件读写，默认布局经快照逐像素对比；真实窗口拖动待手动确认）。

## 功能简介

窗格默认均分（或参考布局给定的固定尺寸）。长路径、宽表格、三方合并窄列等场景下某侧内容看不清时，
拖动两窗格之间的分隔线即可调整；松开鼠标立即保存，重新启动后保持上一次的位置。

| 视图 | 可拖动的分隔线 | 布局键 |
|---|---|---|
| 文本比较 | 左右窗格（并排）/ 上下窗格（上下布局） | `text.split.x` / `text.split.y` |
| 表格比较 | 左右窗格（并排）/ 上下窗格（上下布局） | `table.split.x` / `table.split.y` |
| Hex 比较 | 左右窗格（并排）/ 上下窗格（Over-Under） | `hex.split.x` / `hex.split.y` |
| 文件夹比较、同步 | 左右两棵树（中缝两侧边缘都可拖）；底部日志面板上沿 | `folder.split.x`；`folder.log.h` / `sync.log.h` |
| 文本合并 | 上排三列之间两条；输入区与输出区之间 | `merge.col.a` / `merge.col.b`；`merge.split.y` |
| 表格合并 | 同上 | `table-merge.col.a` / `table-merge.col.b`；`table-merge.split.y` |
| Home | 会话树右边缘 | `home.tree.w` |

不可拖动的（固定内容、调整无意义）：文本/表格的行详情条、Home 底部帮助面板（可用 View 菜单隐藏）、状态栏。

交互约定：

- 分隔线命中区为线两侧各约 3 px，悬停/拖动时光标变为左右或上下调整形状。
- **双击分隔线恢复默认**（均分或原固定尺寸），同样写盘。
- 每侧窗格保留最小尺寸（窗格 60–120 px、日志面板 40 px、Home 会话树 160 px），窗口缩小时按最小尺寸钳制，
  不会把某侧挤没；合并视图的两条列分隔线互相钳制，不会交叉。
- 并排与上下布局各记一份位置，切换布局互不影响；同类视图的所有标签页共用一份位置。
- 拖动中实时重排，松开时写盘。

## 代码地图

- `crates/bc-gui/src/layout.rs`：布局存储（键 → `f32`）。文件 `%APPDATA%\Matcha\layout.txt`（与
  `recent-text.txt` 同目录），首行 `# matcha layout v1`，每行 `键\t值`；未知键原样保留，坏行忽略。
  快照/基准模式关闭持久化（只用默认值、不读不写），单元测试中为线程内存储。
- `crates/bc-gui/src/chrome/splitter.rs`：`Split`（键 + 默认值 + 单位 + 最小尺寸）、`handle()` /
  `vertical_line()` / `horizontal_line()`（命中、光标、按按下点起的位移改值、双击复位、松开写盘）、
  `Columns3`（合并视图三列，两条分隔线互相钳制）。视图在帧首用 `Split::first()` 排版、画完窗格后再调 handle，
  命中条位于窗格控件之上；拖动结果下一帧生效。
- 接入点：`text/view.rs`、`table/view.rs`、`hex/view.rs`、`dir_view.rs`（`chrome_split` / `draw_grid` / 日志面板）、
  `sync_view.rs`、`merge/view.rs`、`table_merge/view.rs`、`home.rs`。

## 关键语义

- 窗格分隔存比例（0–1，按所在区域长度），窗口缩放时按比例跟随；日志面板高度、Home 会话树宽度存像素。
- 所有分隔线的默认位置与改动前的固定布局逐像素一致（快照对比验证），未拖动过就看不出差别。
- 文件夹 / 同步视图中缝（比较 37 px、同步 117 px）宽度不变，只移动它的位置，两种模式共用同一比例；
  路径栏组合框、同步视图的路径框与交换按钮、列头（Name 列吸收余量）、状态栏空闲空间字段都跟随分隔位置
  （此前路径框为写死的像素宽度，窗口变窄时会越界）。
- Hex 并排时两条地址栏跟随窗格分隔（左栏 = 缩略图列 + 左窗格 + 其滚动条，此前为两等分、与窗格错位）；
  两侧每行字节数取较窄窗格可容纳的数目，保证行对齐。Over-Under 时下窗格从与上窗格相同的行开始绘制
  （修复：此前下窗格原点偏移了半个内容高度），可滚动范围按较矮窗格计算。

## 使用与验证

- 单元测试：`cargo test -p bc-gui -- splitter layout pane_divider over_under_panes tree_split_follows`
  （分隔线拖动/钳制/双击复位、三列互相钳制、布局文件读写、文本视图真实指针拖动与跨视图记忆、
  Hex 上下布局两窗格同行、文件夹分隔比例）。
- 手动：打开任一比较，拖动中缝 → 关闭程序 → 再次打开同类比较，中缝位置保持；双击中缝回到均分。
