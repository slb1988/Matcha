# ADR 005：行内碎片合并优先于词边界吸附

- 状态：Wave 3 经协调者确认；对应规格澄清由协调者处理。
- 先对 Unicode 字符序列 diff，再合并相隔不超过 join_gap（默认 3）个相同字符的差异岛。
- gap 合并产生的多碎片区间不再扩大到同一词的未变前后缀。因此 a1b2c→x1y2c 的期望是 a1b/x1y，而非整词。
- 单个词内部的单一差异岛可吸附到整个词（字母数字与下划线）；getValue→setValue 高亮全词。count→total 合并覆盖本身为整个词。
- 纯插入/删除的空侧保持无区间，不为了吸附制造空侧高亮。
- 长于默认 10000 字符的行退化为整行，仍保留重要性；500 KB 回归验证不进入字符级 Myers。
