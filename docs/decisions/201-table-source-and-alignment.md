# ADR 201：表格来源与行配对边界

状态：本波协调者批准。

- 采用 calamine 0.38（唯一新直接第三方依赖）。与 0.30.1 不同，0.38 提供公开样式读取器，实际保留数字格式串/内置编号；字体、填充与写回仍后置。协调者批准 workspace MSRV 统一从 1.80 提高至 1.88；本机工具链 1.99.1。
- 仅值/公式/数字格式进入本波比较。StyleId 是 sheet 内部去重编号，比较时解析属性而非直接比较编号。
- 行对齐复用 core 的策略；Smart 候选仍须满足键相等且重复键 occurrence 一致，除 Unaligned 和显式 AlignmentOverrides 外不得强配不同键。按键稳定排序使用独立排列，core map 的索引仍指向排列位置。
- 日期容差内部为毫秒，提供天/小时构造。系统区域设置由宿主注入 ReadOptions；未注入时使用明确的 invariant（小数点、逗号千分位、YMD、短横线），不猜测或改动进程区域。
- 帮助主题只读解包至系统临时目录：Type/Regional/Columns/Alignment/Sheets/Handling 及命令列表；未访问任何授权文件或安装目录写操作。日期容差帮助未指明单位，因此 API 明确提供单位转换。

- MSRV 提升后，原先由 1.80 屏蔽的 Clippy 建议在共享 crate 启用。协调者另行授权仅机械 lint 修复（as_chunks/repeat_n/is_none_or/is_multiple_of），不改行为和测试，独立 chore(lint) 提交；不放宽任何警告。
- D3 权重：左右唯一性各 0.20、重合度 0.35、相对位置稳定性 0.20、靠左位置 0.05；阈值 0.8，同时要求完整数据两侧均唯一。否则即使重复值的加权分高也不推荐键，符合“无合适键”场景。

- 容差键用非容差部分哈希分组、第一容差分量的相邻桶取候选，逐一按全部键的实际容差复核；不采用会漏掉跨桶相等值的简单舍入。非传递性情况下按源出现顺序消耗首个合格对侧候选，duplicate 统计仍是精确规范化重复数。
- Realign 暂时选择安全全量回退，复用快照/修订号协议但不声称局部增量。对于键变动引起的远端配对变化，这是正确性的保守选择。
- 协调者确认本波原生格式验收是 xlsx/xlsm；D2 提及的 xls/ods 仅是 calamine 能力，不在本波适配/验证，后续按其不同的惰性/合并范围接口处理。

## Wave 2 黄金校准（协调者批准）

同设置原生报告证实：大小写忽略、空白忽略、数值/日期容差内的**原始值差异**是 Unimportant（蓝），不是 Same。协调者修订 table-cell-comparison / table-columns-and-sheets；引擎与 Wave 1 对应断言同步纠正。完全相同值仍 Same，Key 的规范化等值/容差配对不变，Ignore Unimportant 只在视图投影时把 U 当 S；不在黄金解析器归一化掩盖 S↔U。

普通数字的不同拼写（如 1.0/1.00）在 General 下是同一个值，并非容差差异；Text 模式仍比较保留的原拼写。

验证与最终限制见各波 worker report。
