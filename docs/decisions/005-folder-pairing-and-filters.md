## Windows 绑定

原允许三个 windows-sys 特性不足以调用 ReadDirectoryChangesW（依赖 System_IO）
及 NormalizeString（Globalization）。协调者批准五个 Win32 特性：
Foundation、Storage_FileSystem、UI_Shell、System_IO、Globalization。
使用生成的绑定，不手写 FFI；所有 unsafe 限于 bc-vfs Windows 边界。
非 Windows 启用 NFC 返回 Unsupported；不能静默使用不完整 Unicode 表。

## 四组名称过滤

- 包含文件与包含文件夹取交集：没有对应包含项时，该组不限。
- 文件夹包含命中后作用于整个子树；排除文件夹始终屏蔽其后代。
- 排除优先；只有排除项等价于从全选集合减去排除。
- 显式 `...\` 文件路径项可越过父文件夹包含限制，但不能越过任何排除。
- 基准始终存在；实际包含文件的祖先提升为结构可见，不改变文件比较状态。
- 未加 `...\` 的相对路径掩码仍要求父文件夹包含条件成立。

## Flatten 重名规则

每侧按相对路径排序，同名组内从头一一配对，剩余项为孤儿；
不按内容猜配，不重用原来不同配对的内容结果。
视图行携带两侧各自 NodeId，来源位置可追溯，树本身不被改写。
原配对未变时保留已有内容结果；新虚拟配对首先显示快速状态，
后续 UI 调度内容任务应以虚拟配对快照为身份，不能写到不相干的原树行。

## 日期与脚本样例

日期过滤纯函数显式接收本地今日零点（SystemTime）与 UTC 偏移。
不会把 UTC 零点假装为用户本地零点；相对天数在每次求值时据该上下文计算。
解析支持 ISO、M/D/YYYY、英文月份和可选 12/24 小时时间，覆盖帮助全部样例。
夏令时/历史地区偏移由调用方提供，不自造区域数据库。

本机 scripting_reference 的 FILTER Examples 实际六条；
经协调者确认，第七个验收样例补 `filter size:>1MB`。
过滤预设为名称掩码预设（名称 + 掩码），使用 bc-core 的 XML 模型往返；
不新增 serde/日期/正则等第三方依赖。
