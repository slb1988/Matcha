## 024-unaligned（1 项）

- 同输入：`id,name,price` 表头作为数据，左数据 `(1,a,1),(2,b,2)`，右数据顺序相反。
- 入库 `native-rules.xml` 显式指定 `AlignKind=alignNone`、`AlignDef/_0/Kind=alignNone`、空 AlignSort、Key 第 0 列；`TBcAlignKind` 的枚举拼写已由定向只读元数据确认。
- 原生 `table-report` 路径仍输出按键配对后的两行 Same；本项目按明确的 Unaligned 规格逐位置配对，两个数据行及各自 3 格为 Important。
- 原因尚未确认，不把报告路径的观察冒称整个参考 GUI 的行为；没有扩展到对齐算法反汇编。项目保持规格，期望 HTML 原样保留。
- 首行双方的原始表头数据相同；没有删除/替换源行、没有 S/U 归一化、没有添加无关相同行稀释该差异。

回归独立统计所有行状态和所有单元格状态；本项的实际/原生完整三行签名同时锁定，其他差异会使测试失败。大小写、空白、数值和日期容差的原 S↔U 冲突已经协调者批准修正，不再作为已知差异豁免。
