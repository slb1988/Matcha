# Spec Delta

## Purpose

定义文本比较视图逐区域外观与参考一致：工具栏、路径栏、信息头、缩略图、窗格、行详情、状态栏与标题。

## ADDED Requirements

### Requirement: 文本视图布局
文本比较视图 SHALL 自上而下呈现菜单栏、工具栏、每侧路径栏、每侧信息头（修改时间、字节数、格式下拉、编码下拉、行尾）、左侧缩略图栏与双窗格、每侧窗格状态（行:列、当前文本类别）、行详情两行、底部状态栏（差异区段数、当前行状态、Insert/Overwrite、Load time）；各命名区域与参考偏差 MUST 在 ±2 px 内。

#### Scenario: 基础场景几何
- **WHEN** 对 `text-basic` 场景运行对照工具
- **THEN** 所有命名区域偏差 ≤ 2 px

### Requirement: 差异着色
窗格 SHALL 按参考颜色呈现：差异行底色、差异字符前景色、不重要差异色、缺行处斜纹、文件末尾之后网纹、当前行与选区；行号与差异箭头位于各自槽位。

#### Scenario: 缺行斜纹
- **WHEN** 左侧有右侧不存在的行
- **THEN** 右侧对应位置以斜纹填充且无行号，左侧箭头槽显示指向右的箭头

### Requirement: 功能入口不丢失
换肤 SHALL 保留换肤前全部文本视图功能入口（迁到菜单、工具栏或右键菜单），并在报告中给出迁移清单。

#### Scenario: Swap 入口
- **WHEN** 用户点击工具栏 Swap
- **THEN** 行为与换肤前 Swap Sides 一致
