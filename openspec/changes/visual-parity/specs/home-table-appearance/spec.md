# Spec Delta

## Purpose

定义 Home 会话启动页与表格比较视图逐区域外观与参考一致。

## ADDED Requirements

### Requirement: Home 会话启动页
Home SHALL 呈现参考布局：左侧会话树（分组与最近会话）、右侧新会话类型图标网格及其文字、菜单与工具栏；仅显示本项目已实现的会话类型为可用，其余按参考位置显示为禁用。

#### Scenario: 新会话网格
- **WHEN** 打开 Home
- **THEN** 新会话类型按参考顺序与网格排列，未实现类型为禁用态

### Requirement: 表格比较外观
表格比较视图 SHALL 按参考呈现菜单、工具栏、路径栏、信息头、网格（表头、行号、行状态色、差异单元格色、键列标记）、sheet 标签、行详情与状态栏；命名区域偏差 MUST ≤ 2 px，本项目超越功能的入口放在不破坏参考布局的位置（菜单或分体下拉）。

#### Scenario: 表格基础场景几何
- **WHEN** 对 `table-basic` 场景运行对照工具
- **THEN** 所有命名区域偏差 ≤ 2 px
