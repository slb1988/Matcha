# Spec Delta

## Purpose

定义判定两个同名文件"相同/不同/较新"的准则管线：只读目录即可完成的快速测试、需要读取文件的内容测试、版本比较，以及它们的组合与覆盖规则，与参考工具的 Comparison 设置和 `criteria` 脚本命令一致。

## ADDED Requirements

### Requirement: 快速测试
系统 SHALL 支持以下仅凭目录信息的测试，每项可独立开关：文件大小；时间戳（容差秒数，默认 2 秒；"忽略夏令时差异"把恰好 1 小时的差异视为相同；"忽略时区差异"把整小时倍数的差异视为相同）；文件名大小写；文件属性（归档、系统、隐藏、只读各自可选）。

#### Scenario: 容差内的时间戳
- **WHEN** 两文件修改时间相差 1 秒且容差为 2 秒
- **THEN** 时间戳测试判定相同

#### Scenario: 夏令时差异
- **WHEN** 两文件修改时间恰好相差 1 小时且开启"忽略夏令时差异"
- **THEN** 时间戳测试判定相同；关闭该项则判定较新/较旧

#### Scenario: 归档属性默认不比较
- **WHEN** 用户未更改默认设置
- **THEN** 归档属性差异不影响状态

### Requirement: 内容测试
系统 SHALL 支持三种互斥的内容比较：CRC、二进制逐字节、规则比较（按文件格式忽略行尾/空白/注释等不重要差异）；可选"快速测试相同则跳过内容测试"与"内容结果覆盖快速测试"。内容测试在后台执行、可取消，并在中央列给出结果。

#### Scenario: 二进制相同覆盖时间戳
- **WHEN** 时间戳不同、二进制比较相同且覆盖开启
- **THEN** 状态为"相同"

#### Scenario: 规则比较只有不重要差异
- **WHEN** 两个 `.cpp` 仅注释不同且采用规则比较
- **THEN** 状态为"相似（仅不重要差异）"；开启"忽略不重要差异"后视为相同

#### Scenario: 快速测试相同则跳过
- **WHEN** 大小与时间戳都相同且"跳过"开启
- **THEN** 不读取文件内容，状态为相同

#### Scenario: 二进制比较提前退出
- **WHEN** 两个 1 GB 文件在前 4 KB 即不同
- **THEN** 比较在读到首个不同块后结束，不继续读完整文件

### Requirement: 版本比较
系统 SHALL 可选比较可执行文件的版本信息（PE 版本资源），差异计入"不同"。

#### Scenario: 版本不同
- **WHEN** 开启版本比较且两个 `.dll` 版本号不同、其他测试相同
- **THEN** 状态为不同，版本列显示两侧版本

### Requirement: 状态推导
系统 SHALL 按以下顺序推导状态：任一侧缺失→孤儿；否则快速测试判定不同→"较新/较旧"（时间戳）或"不同"（其他）；内容测试结果存在时按覆盖规则参与；全部相同→相同。时间戳较新的一侧 MUST 被标记为"较新"，供显示过滤与同步使用。

#### Scenario: 左侧较新
- **WHEN** 左侧修改时间晚于右侧超过容差
- **THEN** 左侧标记较新，右侧标记较旧，显示过滤 Show Left Newer 包含该行

### Requirement: 准则的脚本等价
准则设置 SHALL 与 `criteria` 脚本命令的字段一一对应（`attrib:` / `version` / `timestamp:nsec;IgnoreDST` / `size|CRC|binary|rules-based` / `timezone:` / `follow-symlinks` / `ignore-unimportant`），内部 API 为脚本引擎直接复用。

#### Scenario: 脚本设置准则
- **WHEN** 调用内部 API 应用 `criteria timestamp:2sec;IgnoreDST rules-based`
- **THEN** 时间戳容差为 2 秒、忽略夏令时开启、内容比较为规则比较，与在 GUI 中设置效果相同
