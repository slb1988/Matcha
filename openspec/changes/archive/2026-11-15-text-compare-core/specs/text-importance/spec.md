# Spec Delta

## Purpose

定义"重要差异"与"不重要差异"的判定规则：文本按文件格式的语法分成元素，元素类别、空白、大小写、行尾和用户规则共同决定一处差异是否重要，并决定视图着色、"忽略不重要差异"开关以及文件夹规则比较的结论。

## ADDED Requirements

### Requirement: 差异三态
每一对已配对的行以及每个差异区块 SHALL 被归为三态之一：相同、不重要差异、重要差异。插入/删除行默认为重要，除非其全部内容由不重要元素构成。

#### Scenario: 仅注释不同
- **WHEN** 文件格式把 Comment 元素标为不重要，且两行只在注释文字上不同
- **THEN** 该行对归为"不重要差异"

#### Scenario: 代码与注释同时不同
- **WHEN** 两行在注释和一个标识符上都不同
- **THEN** 该行对归为"重要差异"

#### Scenario: 整行注释被删除
- **WHEN** 左侧多出一行纯注释且 Comment 为不重要
- **THEN** 该删除行归为"不重要差异"

### Requirement: 元素级重要性可配置
系统 SHALL 允许按文件格式的 10 类语法元素（Comment、Directive、EnvironmentVar、Identifier、Indent、Keyword、LineNum、Number、Operator、String）分别设定"重要/不重要"，默认全部重要，并允许会话级覆盖格式默认值。

#### Scenario: 会话覆盖
- **WHEN** 格式默认 String 为重要，用户在会话设置中把 String 设为不重要
- **THEN** 仅该会话内字符串差异按不重要处理，格式默认值不变

### Requirement: 空白、大小写与行尾选项
系统 SHALL 提供独立开关：行首空白、行内空白、行尾空白、字符大小写、行尾风格差异是否视为不重要；行尾风格默认不重要，其余默认重要。元素级的大小写显著性（如 Keyword 不区分大小写）MUST 优先于全局开关。

#### Scenario: 仅缩进不同
- **WHEN** 开启"行首空白不重要"，两行仅缩进不同
- **THEN** 该行对为不重要差异；关闭该开关后变为重要差异

#### Scenario: 关键字大小写
- **WHEN** 格式声明 Keyword 不区分大小写，两行仅 `BEGIN` 与 `begin` 不同
- **THEN** 该行对为"不重要差异"（与参考工具一致，不归为"相同"），即使全局"大小写重要"开启

#### Scenario: CRLF 与 LF
- **WHEN** 两份内容相同但一份用 CRLF、另一份用 LF
- **THEN** 所有行归为"相同"，并在状态区提示行尾风格不同

### Requirement: 不重要文本规则与替换规则
系统 SHALL 支持会话级"不重要文本"规则（字面或正则，可限定元素类别）和"替换"规则（from→to，字面或正则，可双向、可全词），命中的差异按不重要处理。

#### Scenario: 时间戳替换
- **WHEN** 存在正则替换规则 `\d{4}-\d{2}-\d{2}` → `DATE`，两行仅日期不同
- **THEN** 该行对为不重要差异

#### Scenario: 双向替换
- **WHEN** 规则 `colour`↔`color` 设为双向
- **THEN** 无论哪一侧出现 `colour`、另一侧出现 `color`，该差异均为不重要

### Requirement: 忽略不重要差异
系统 SHALL 提供"忽略不重要差异"开关；开启时不重要差异在导航、计数与视图上按"相同"处理，但原始文本不被修改。

#### Scenario: 开关影响导航
- **WHEN** 开启"忽略不重要差异"且某区块仅含不重要差异
- **THEN** "下一差异"跳过该区块，差异计数不包含它

#### Scenario: 开关关闭恢复
- **WHEN** 关闭该开关
- **THEN** 该区块重新以不重要差异的颜色显示并参与导航

### Requirement: 区块级传播
系统 SHALL 把行级三态向差异区块传播：区块内全部行为相同或不重要时整块为不重要；任一行为重要则整块为重要。

#### Scenario: 混合区块
- **WHEN** 一个连续区块包含 2 行不重要差异和 1 行重要差异
- **THEN** 该区块整体按重要差异着色与计数

### Requirement: 差异统计
系统 SHALL 在视图信息区报告重要差异区块数、不重要差异区块数、仅左/仅右行数，并随"忽略不重要差异"开关实时更新。

#### Scenario: 统计显示
- **WHEN** 比较完成
- **THEN** 信息区显示各项计数，且与导航可到达的区块数一致
